# LifeOS フォルダ構成

日常生活から個人活動までを 1 か所で管理するための構成です。

| フォルダ | 役割 | 例 |
|---|---|---|
| `00_Inbox` | 一時置き場。迷ったらここ | ダウンロードしたPDF、メモ |
| `10_Life` | 生活の管理 | 家計簿、保険、通院記録、保証書 |
| `20_Projects` | 進行中の個人活動（実体は `~/Dev` へのリンク） | Web開発、DTM、サイト運営 |
| `30_Learning` | 学んでいること | 講座ノート、読書メモ |
| `40_Resources` | 繰り返し使う参照物 | テンプレート、手順書、素材 |
| `50_Media` | 写真・動画 | 年ごとに整理 |
| `90_Archive` | 終わったもの | 完了プロジェクト、古い契約 |

## ルール

1. **迷ったら `00_Inbox`** — 保存時に悩まない。週 1 回（例：日曜夜）に仕分ける。
2. **番号で並び順を固定** — 新しいカテゴリは空き番号（17、25…）を使う。
3. **ファイル名は `YYYY-MM-DD_内容`** — 例：`2026-10-23_電気料金.pdf`。日付順に並び検索しやすい。
4. **終わったら `90_Archive` へ移動** — 削除せず移すだけ。進行中フォルダを軽く保つ。
5. **階層は 3 段まで** — 深くすると探せなくなる。

## 勤怠記録

`10_Life/17_勤怠/kintai` で出退勤を記録できます。使い方は同じフォルダの README を参照。

## 週報（Qiita）

`30_Learning/35_週報/qiita` で1週間の活動をまとめて Qiita に投稿できます。毎週日曜夜に自動投稿されます。使い方・初回のトークン設定は同じフォルダの README を参照。

## 個人開発の始め方

個人開発は `~/Dev` で開発・運用します（Documents の外なので iCloud 同期で Git や node_modules が壊れません）。LifeOS の `20_Projects` は `~/Dev` へのショートカットです。

1. `~/Dev/24_アイデア/アイデア一覧.md` にアイデアを書く
2. やると決めたらテンプレートから作成：

```bash
~/Dev/new.sh 21_Web開発 勤怠アプリ
```

```
~/Dev/21_Web開発/2026_勤怠アプリ/
├── docs/      仕様・メモ（README.md に概要・機能・ログ）
├── assets/    画像・素材
└── src/       コード（Git管理）
```
