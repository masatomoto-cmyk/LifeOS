# 2026-10-29 作業記録: Roland S-1 を Claude が操作できるようにした

## 概要
- 日付: 2026‑10‑29  
- 題: Roland S‑1 を Claude が操作できるようにした  
- 使用した素材: `S1.zip`（README, s1‑controls.pdf, Roland S‑1 Control 2.10.8 インストーラ）  
- プラグイン: Logic Pro 専用 AU（MIDI FX、内部は Cabbage/Csound）  

## やったこと
- `bin/s1ctl.py` と `bin/s1`（`~/.local/bin/s1` へシンボリックリンク）を作成  
- Python 仮想環境 `~/.venvs/s1` を構築し `mido, python-rtmidi, numpy, pypdf` をインストール  
- CC 対応表を Roland 公式マニュアル v1.02 の Control change list と照合し一致させた  
- 環境変数 `S1_CHANNEL`（デフォルト 12）で受信チャンネルを設定可能にした  

## 使い方
```bash
s1 list                         # 操作できるパラメータの一覧
s1 set cutoff=40 reso=90        # パラメータ設定
s1 cc 74 40                     # 任意 CC 送信
s1 note C4                      # 単音ノート送信
s1 play "C4 E4 G4" --dur 0.25   # フレーズ演奏
s1 chord "C4 E4 G4" --dur 1    # 和音（Poly モードで）
s1 pc 3                         # パターン切り替え（0 始まり）
s1 bend 4000                    # ピッチベンド（-8192〜8191、0=中央）
s1 panic                        # 全音符オフ
s1 test                         # USB 音声録音し音量・音程測定
```  

## わかったこと・つまずき
- 初期はチャンネル 1 に送信していたが S‑1 本体はチャンネル 12 受信していた  
- シーケンサーが常に鳴り続き、MIDI 変化が埋もれたため 16 チャンネルを順にテストし 12 を特定  
- `cutoff` を 10・60・127 にすると、音の明るさ（周波数の重心）が 276・1652・2707 Hz に変化（つまみが効いている）
- `RANGE` (CC14) は 0〜5 で 1 段ごとに 1 オクターブ、標準は 3（8'）  
- AIRA Link は Off、Identity Request に対して本体は応答しない  
- 本体のつまみや鍵盤操作は USB MIDI で送信されない（送信側は未確認）
