# MIDI 2.0 対応機材まとめ（2026年10月版）— 今そろえると何が変わる？

> 下書き（2026-10-28）。対応状況は各メーカーの公式ページで確かめた内容のみ。投稿前に価格・ファームウェアの最新版を再確認する。

## MIDI 2.0 で何が変わるのか

MIDI 1.0 が生まれたのは 1983 年。40 年以上使われてきた規格が、ようやく本格的に新しくなりつつあります。DTM をしている人にとって大きい変化は次の 3 つです。

- **細かさが段違い**：ベロシティは 128 段階から 16 ビット（65,536 段階）に、コントロールチェンジやアフタータッチは 32 ビットに。フィルターをゆっくり開けたときの「段差」が消えます。
- **1 音ごとの表現**：ノートごとにピッチベンドやコントロールを送れるので、和音の中の 1 音だけを揺らす、といった演奏がしやすくなります。
- **機器同士が話し合う**：MIDI-CI（Capability Inquiry）や Property Exchange で、つないだ機器が「何ができるか」「どんな設定か」を自動でやり取りします。プリセット名の表示や設定の自動化がしやすくなります。

ただし、**鍵盤・OS・DAW・音源のどれか 1 つでも MIDI 1.0 だと、全体は 1.0 として動きます**。ここが一番の注意点です。

## OS の対応状況

| OS | 状況 |
|---|---|
| macOS | Core MIDI が MIDI 2.0（Universal MIDI Packet）に対応済み。Native Instruments の Kontrol S MK3 は MIDI 2.0 モードに macOS 13.5 以上を求めている |
| Windows 11 | 2026 年 2 月 17 日、Microsoft が「Windows MIDI Services」の一般提供を発表。24H2・25H2 から段階的に配信。MIDI 2.0 対応に加え、1 つの機器を複数のアプリで同時に使える「マルチクライアント」にもようやく対応 |

Windows の新しい仕組みでは、MIDI 2.0 の細かい値を MIDI 1.0 のアプリにも自動で変換して渡してくれます。今使っているソフトがすぐ動かなくなる、ということはありません。

## 対応している鍵盤（メーカー公式で確認できたもの）

### Roland A-88MKII
88 鍵のハンマーアクション。システムソフトウェア Ver.2.00 以降で MIDI 2.0 に対応します。発売後のアップデートで対応した、MIDI 2.0 鍵盤の先駆けです。ピアノを弾く人向け。

### KORG Keystage（49 鍵 / 61 鍵）
KORG 初の MIDI 2.0 コントローラー。セミウェイト鍵盤でポリフォニック・アフタータッチ（1 鍵ごとの押し込み）に対応し、MIDI 2.0 の Property Exchange でつないだソフトの情報を画面に表示できます。シンセを弾く人、表現の幅を広げたい人向け。

### Native Instruments Kontrol S49 / S61 / S88 MK3
ファームウェア 2.1.2 で MIDI 2.0 の高解像度データ（16 ビットのベロシティ、32 ビットのコントロールチェンジ・アフタータッチ）に対応。本体の設定で MIDI 2.0 モードに切り替えて使います。NI 公式も「すべての DAW・プラグイン・OS が MIDI 2.0 に対応しているわけではない」としていて、うまく動かないときは MIDI 1.0 モードに戻せます。

## DAW の対応はまだ途中

鍵盤と OS がそろっても、DAW 側の対応はまだばらつきがあります。

- **Cubase**：バージョン 13 から高解像度データの扱いに対応を始めていますが、実際の MIDI 2.0 機器とのやり取りはまだ限定的、という声がユーザーフォーラムで出ています。
- **Logic Pro**：NI のコミュニティでは、Kontrol S MK3 を MIDI 2.0 モードで Logic のミキサー操作に使うと不具合が出るという報告があり、NI 側も「現時点では Logic での MIDI 2.0 利用はおすすめしない」と回答していました。

使っている DAW のリリースノートで「MIDI 2.0」「UMP」の記載を確かめてから、2.0 モードを試すのが安全です。

## 結局、今買うべき？

- **新しく鍵盤を買うなら**：MIDI 2.0 対応モデルを選んでおいて損はありません。1.0 機器としても普通に使えるので、DAW の対応が追いついたときにそのまま恩恵を受けられます。
- **今の鍵盤で困っていないなら**：買い替えを急ぐ必要はまだありません。DAW と音源の対応がそろうのを待ってからでも遅くありません。
- **Windows ユーザー**：マルチクライアント対応だけでも、Windows 11 を最新にしておく価値があります。
