## 1. 各動画の要約

### 動画1: 【How to make】Kawaii Future Bassの作り方｜FL Studio 2025

- URL: https://www.youtube.com/watch?v=2ImeRc6pRZ4
- チャンネル: mikineko（みき猫）
- DAW は FL Studio 2025。**BPM 160**（キーは字幕が「160AK」で不明確）。コードはまず**丸サ進行**のルート（根音）を決め、上に和音を重ね、**転回**させて自然でおしゃれな響きにする。
- イントロ: リードは「ふわふわ」にするため**サイン波のリード**（エフェクトなし）。メロディはノートを短くして隙間を空ける。アルペジオは透明感のあるプラック＋マリンバ＋ピチカートを重ねる。コードは「もちもち」したプラックで、オートメーションで「わうわう」させる。キック、クラッシュ、リバースクラッシュを入れる。
- ビルドアップ: グロッケン、ディストーションで歪ませた **808**、ボーカルチョップ（Endless Smile のオートメーション）を追加。クラップ、スネアは**オートメーションでピッチを上げていく**。クラッシュ、ライザーなどの FX。
- ドロップ: コードは**スーパーソー**、ベース＋サブベース、メロディは3種類を重ねる。コードとベースに**ピッチを上げ下げするオートメーション**。ハイハットを刻み、スネア、キックはコードと同じタイミング、そのキックと同じタイミングでクラッシュ。フィルを入れ、サイドチェインは **Kickstart**。最後にコードを細かく刻んだり別のコードを足したりして「限界化」させる。

### 動画2: 【Kawaii Future Bass 作り方】初心者のためのhow to【logic pro x】

- URL: https://www.youtube.com/watch?v=5dNFC1hy_JU
- チャンネル: C-takebeats. computer music Channel（しーたけびーつ）
- DAW は **Logic Pro X**、音色はほぼ **Serum ＋無料のプリセットパック**。BPM・キーは話していない。
- 構成: バース（A メロ）→ビルドアップ→ドロップで、**コード進行とリードメロディは同じものを繰り返す**。盛り上がりは**音の厚さ（トラック数）と FX・ドラム**で作る。コードはバース5トラック→ビルドアップ7→ドロップ10（ベース込み）、リードは2→5→6。
- コード: メジャーセブンス・セブンス・テンションを多く使う。2回し目の Am7 を短くして**半音ずつ下がるクリシェ**にする。**オープンボイシング**にし、低音域は1オクターブ、少なくとも7半音（完全5度）以上空ける（ロー・インターバル・リミット）。役割を分けて**レイヤー**（ソフトピアノ＋ハードピアノ、ドロップは高域・中域・全体の3つのシンセ＋ストリングス）。
- リード: **装飾音（グレースノート）**を入れる。オクターブ違いのシンセベルを重ねる。
- ベース: リズムは**ベタ打ち**でよく、音作りを優先。サブベースを重ねる。ベースは **100Hz あたりでローカットして 100〜300Hz 中心**、サブベースは **50Hz あたり**を担当させ、EQ でそれ以外を削る。
- コード・リード・ベースに**ダッキング**（Nicky Romero の **Kickstart**）。FX はバースにリバースシンバル・クラッシュ・インパクト・ダウンリフター、ビルドアップにアップリフター・ビルドアップ用スネア・かわいいボイス。ドラムはドロップだけで、**ハーフテンポ（3拍目にスネア／クラップ）**と**トラップのハイハット**（16分の中に32分などの細かい音）。ドラムは打ち込みよりサンプルを勧めている。

### 動画3: よくあるKawaii Future Bassの作り方

- URL: https://www.youtube.com/watch?v=DRgSCVUEDyA
- チャンネル: 一斗缶 -ittokan-
- 自作曲「よくある可愛いフューチャーベース」の FL Studio プロジェクトを解説する長い配信アーカイブ。**キーは C# メジャー**（いつも C メジャーで打ち込んでから移調する）。BPM は話していない。
- コード: **丸サ進行（4-3-6-5）を1曲通して同じ**に使い、セクションごとに**音数だけ増やす**。ほぼ全部 9th 系（m9・M9 など）。ルートを抜くと別のコードに聞こえる**オンコード**の組み方が好き。つなぎに**ディミニッシュ**を挟む。ドロップでは半音ずつ下がる動きを追加し、マイナー9のコードを平行移動させる。
- ドラム: **ハーフテンポ（ドン・パン）でないとフューチャーベースではない**。ビルドアップは**ジャージークラブ風「ドンドン・ドドド」**。ドロップは**コードと一緒にクラッシュシンバルを鳴らす**（必ず入れる）。ハイハット・パーカッションは**ループ素材を切り貼り**して合わせる。入れすぎるとごちゃごちゃになる。
- 音色: コードの「芯」の音1つに、ドロップだけ**低域と高域を補強する2つを重ねる**。コードは**マクロ（カットオフ）のオートメーション**で、A メロ2回目で少し開き、ビルドアップで徐々に開き、ドロップ直前で一気に下げ、ドロップで開く。ドロップのコードは**1発で長く伸ばし、その間に「おかず」**を入れる（4小節で1セット）。ベースは 808 系のサブ＋ミッドベース（ドロップから）で、ドロップでは**ピッチベンドとフィルターで「デン」と下がる**効果。
- アルペジオ・メロディ: アルペジオは**1度と5度を起点**にし、4度・7度は避ける（ペンタトニックだと失敗しにくい）。メロディとアルペジオが同じ波形（サイン波）だとぶつかるので、波形やユニゾンで住み分ける。メロディは**音域を広げすぎず、口で歌える**ものに。脇役は **Haas 効果で左右へ**、主役は真ん中。
- ミックス・マスター: 低音は別トラックで担当し他はローカット気味。マスタリングは 32bit float で書き出してから、クリッパー→OTT→コンプ→Ozone（Dynamics・Impact・Stabilizer・Maximizer）→Pro-Q→Invisible Limiter（Clip）。ビルドアップでローカットしなかったせいでビルドアップが大きくなり、音割れした失敗談がある。

## 3. Logic Pro での操作手順

ここでは3本の共通点をもとに、Logic Pro の純正音源・プラグインだけで1コーラス（約40小節）を作る。

### 3-0. 作る曲の設計

| 項目 | 値 | 出典 |
|---|---|---|
| テンポ | 160 BPM（ハーフテンポなので体感は 80） | 動画1 |
| キー | C メジャーで打ち込み、最後に +1 半音して **C# メジャー** | 動画3（C で打ち込んでから移調するやり方も動画3） |
| 拍子 | 4/4 | （一般知識） |
| コード | 丸サ進行 4小節を1曲通して繰り返す | 動画1・動画3 |

構成（動画3の8小節単位をもとに、小節数は Claude が決めた）:

| 区間 | 小節 | 内容 |
|---|---|---|
| イントロ／A メロ1 | 1〜8 | コード（プラック）、リード、アルペジオ。ドラムなしか控えめ（動画3） |
| A メロ2 | 9〜16 | ドラム（ループ的なハイハット・パーカッション）が入る（動画3）。コードのフィルターを少し開く |
| ビルドアップ | 17〜24 | グロッケン・808 を追加、ジャージークラブのキック、スネアロールのピッチ上げ、ライザー |
| ドロップ | 25〜40 | スーパーソーのコード、ベース＋サブ、ハーフテンポのドラム、クラッシュ、サイドチェイン |

### 3-1. プロジェクトの設定

1. `File > New`（`⇧⌘N`）→ プロジェクト選択画面が出る → `Empty Project` を選ぶ → 「新規トラック」ダイアログが出る。
2. ダイアログで `Software Instrument` を選び `Create` → 空のソフトウェア音源トラックが1本できる。
3. コントロールバーの LCD のテンポ表示をダブルクリック → 数値入力欄になる → `160` と入力して Return → テンポ表示が 160 になる。
4. LCD のキー表示（初期値は `Cmaj`）をクリック → メニューが出る → `C` と `major` を選ぶ → `Cmaj` のまま（あとで移調するので C で作る）。
5. 拍子が `4/4` であることを確認する。
6. `K` でメトロノームのオン／オフ → 再生中にクリックが鳴る（Claude には聞こえないので、コントロールバーのメトロノームボタンが点灯しているかで確認）。
7. **スクリーンショット**: テンポ 160、キー Cmaj、4/4 が表示されているか確認。
8. 保存する前にユーザーに名前と場所を確認 → `File > Save As…`（`⇧⌘S`）→ 保存ダイアログ → 指定どおりに保存。

**代替（動画外）**: 動画で使っている Serum（動画2・3）、Sylenth1・Diva・Keyscape（動画3）は Logic にないので、Alchemy・Retro Synth・ES2・Vintage Electric Piano で置き換える。プリセット名は Logic のバージョンで変わるため、Library の検索欄に「Pluck」「Saw」「Bell」「Pad」「Sub」「808」などを入れて選び、スクリーンショットで音源名を確かめる。

音色の目安（一般知識。画面で値を確かめながら設定する）:

- **Lead Sine（Retro Synth）**: `Analog` モード → オシレーターをサイン波（またはできるだけ丸い波形）→ フィルターはほぼ全開 → Amp エンベロープは Attack 0 付近・Release 短め → 「ふわふわ」したサイン波リードになる（動画1）。
- **Arp（Retro Synth）**: ノコギリ波 → Amp エンベロープの Decay・Release を短く → 「ペペペ」と短く鳴る音（動画3がこの作り方を紹介）。メロディがサイン波なので、アルペジオはノコギリ波にして**波形を分ける**（動画3）。
- **Chord Saw（Alchemy）**: プリセット検索で「Supersaw」等を探す。なければ Alchemy の画面上部の File メニューから Initialize Preset で初期化 → Source A を VA（バーチャルアナログ）のノコギリ波 → Unison の voices を 7 前後・Detune を少し → 広がった厚いスーパーソーになる（一般知識）。
- **Sub Bass（ES2）**: オシレーター1をサイン波 → ほかのオシレーターをオフ → Glide 0 → 低音だけの丸いサブになる（一般知識）。

### 3-3. コード（Chord Pluck に打ち込む）

**コード進行（丸サ進行、C メジャーで書く）**: 1小節に1コード、4小節で1回し（動画1・動画3。9th 系にしたのは動画3、ボイシングの具体的な音は Claude が決めた）。

| 小節 | コード | 右手（Chord トラックに入れる音） | ベース（Bass に入れる音） |
|---|---|---|---|
| 1 | FM9 | A3・C4・E4・G4 | F1（サブ）／F2（ミッド） |
| 2 | E7(♭9) | G#3・B3・D4・F4 | E1／E2 |
| 3 | Am9 | G3・B3・C4・E4 | A1／A2 |
| 4（1〜2拍） | Gm9 | A3・B♭3・D4・F4 | G1／G2 |
| 4（3〜4拍） | C9 | B♭3・D4・E4・G4 | C2／C3 |

- 右手はルート（根音）を抜いている。ルートはベースが鳴らすので、ルートを抜くと別のコードにも聞こえる「オンコード」の響きになる（動画3）。
- 低音域は音を詰めない。ベースと右手の一番下の音は1オクターブ以上離れている（動画2のロー・インターバル・リミット）。
- 2回し目（5〜8小節目など）の3小節目は、Am9 を2拍に縮め、3拍目に同じ形を半音下げた A♭m9（右手の4音すべてを半音下げる）を1拍、4拍目は次の Gm9 へ戻る → 半音ずつ下がるクリシェ（動画2のクリシェ。どの音を下げるかは字幕から読み取れないので、ここでは和音全体を半音下げる形にした）。

操作:

1. トラック1（Chord Pluck）を選ぶ → 1小節目から5小節目までのトラック領域で右クリック → `Create MIDI Region` → 4小節の空の MIDI リージョンができる（長さは右下端をドラッグして調整）。
2. リージョンを選んで `P` → 下にピアノロールが開く。
3. ピアノロールで鉛筆ツール（`T` でツールメニュー → Pencil）または `⌘` を押しながらクリックでノートを置く → 上の表の音を、1小節ずつ全音符（Gm9 と C9 は2分音符）で入れる。
4. 置いたノートを全選択（`⌘A`）→ `Q`（Quantize）→ グリッドにぴったり揃う。
5. **スクリーンショット**: ピアノロールの鍵盤の音名と、ノートの位置・長さが表と一致するか確認する。
6. リージョンを選んで `⌘R`（Repeat Regions）→ 回数 `9` 程度 → 40小節目まで繰り返しが並ぶ。2回し目のクリシェの小節だけノートを直す。
7. トラック2（Chord Pad）にリージョンをコピー（`⌥` を押しながらドラッグ）→ パッドは右手の音だけでよい（もともとルートなし）。A メロ2回目は**全音符をやめて、スネアに合わせて短く切る**（動画3）。
8. ドロップ（25〜40小節）では Chord Saw・Chord Low・Chord High にも同じ和音を入れる（下の 3-6）。

**フィルターのオートメーション（Chord Pluck）**（動画3の流れ。動画1の「わうわう」もこれで作る）:

1. `A` → トラックのオートメーション表示がオンになる → Chord Pluck のトラックヘッダーにオートメーションのメニューが出る。
2. メニューから Alchemy のフィルターのカットオフ（`Cutoff` などの名前。Alchemy の場合は Smart Control の「Cutoff」に割り当てられていることが多い）を選ぶ → オートメーションの線が表示される。
3. 次の形に点を打つ: 1〜8小節は低め（こもった音）→ 9小節目で少し上げる → 17〜24小節で徐々に上げる → 24小節目の最後の拍で一気に下げる → 25小節目で一気に上げる。
4. 動画1の「わうわう」は、1拍ごとにカットオフを上下させる短い山を描く（イントロの一部だけ）。
5. **スクリーンショット**: オートメーションの線の形を確認する。再生してフィルターのつまみが動くか、プラグイン画面を開いて確かめる。

### 3-4. メロディ（Lead Sine に打ち込む）

動画ではメロディの音そのものは示されていない。下の4小節は、動画の方針（音域を広げすぎない・口で歌える・同じリズムを繰り返す・コードの音を中心にする・短いノートで隙間を空ける・装飾音）に合わせて **Claude が作った例（一般知識）**。1拍＝4分音符。

| 小節 | 拍の位置と音（長さはすべて8分音符） |
|---|---|
| 1（FM9） | 1拍: E5 ／ 1.5拍: G5 ／ 2.5拍: A5 ／ 3拍: G5 ／ 4拍: E5 |
| 2（E7♭9） | 1拍: D5 ／ 1.5拍: F5 ／ 2.5拍: G#5 ／ 3拍: F5 ／ 4拍: D5 |
| 3（Am9） | 1拍: C5 ／ 1.5拍: E5 ／ 2.5拍: G5 ／ 3拍: E5 ／ 4拍: C5 |
| 4（Gm9→C9） | 1拍: D5 ／ 1.5拍: F5 ／ 2.5拍: E5 ／ 3拍: D5 ／ 3.5拍: E5（2拍ぶん伸ばす） |

操作:

1. Lead Sine に 1〜5小節の MIDI リージョンを作る → `P` でピアノロール。
2. グリッドを 1/8（ピアノロール上部の `Grid` または `Time Quantize` を 1/8）にしてノートを置く → 表どおりに並ぶ。
3. **装飾音（グレースノート）**: 2・4小節目の頭の音の直前に、半音下（または全音下）の音を 1/32 程度の長さで置く → 下からしゃくり上げる感じになる（動画2の装飾音。動画1の字幕にも「半音下から」らしい言い方があるが、聞き取りが不確か）。
4. リージョンを `⌘R` で繰り返す。動画3は「A メロ・ビルドアップ・ドロップでメロディを変える方が好き」、動画2は「同じメロディを繰り返すだけでよい」と言っている。初回は同じメロディで作り、余裕があればドロップで音を変える。
5. Lead Bell に同じリージョンを `⌥` ドラッグでコピー → コピーしたリージョンを選び、Region inspector（`I`）の `Transpose` を `+12` にする → 1オクターブ上のベルのレイヤーになる（動画2）。
6. レイヤーの数はセクションで増やす（動画2: リード2→5→6、動画3: 基本の音に少しずつ重ねる）。ここでは A メロ: Lead Sine のみ、A メロ2: ＋Lead Bell、ドロップ: ＋Glock（または別のプラック）とする。
7. **スクリーンショット**: ピアノロールで音名と位置を確認する。

### 3-5. アルペジオ（Arp）

1. Arp トラックに MIDI リージョンを作る → 1小節に16分音符で、**1度と5度（C と G）を起点・終点にし、間を C・D・E・G・A（ペンタトニック）で埋めた**フレーズを入れる（動画3の作り方。具体的な並びは一般知識）。例: C5 G5 E5 G5 C6 G5 E5 D5 を2回で1小節。
2. 4度（F）と7度（B）は使わない → どのコードの上でもぶつかりにくい（動画3）。
3. 曲中はほぼずっと鳴らしてよい（動画3）。フィルの小節だけ消す。
4. **代替（動画外）**: 動画3は左右に動かすパンのオートメーションと Haas 系プラグインを使っている。Logic では `A` → オートメーションで `Pan` を選び、1小節で左→右→左と波形を描く。または Logic の `Arpeggiator`（MIDI FX）でコードからアルペジオを自動生成してもよい（一般知識）。

### 3-6. ドロップのコード（スーパーソー＋補強）

1. Chord Saw（Alchemy のスーパーソー）に 25〜40小節のリージョンを作り、3-3の和音を入れる。
2. ドロップのリズムは2通りある。
   - 動画3: **1発で長く伸ばす**（全音符）＋コードとコードの間に「おかず」（短いフレーズ）を入れる。4小節で1セット。
   - 動画1: 最後は**コードを細かく刻む**（16分音符で連打）。
   ここでは 25〜32小節を動画3の伸ばし、33〜40小節を動画1の刻みにする。
3. Chord Low（Retro Synth のノコギリ波）に同じ和音を1オクターブ下（`Transpose -12`）で入れる → 中低域の「ザラザラした太さ」の補強（動画3）。
4. Chord High（ベル・明るいプラック）に同じ和音を1オクターブ上で入れる → 高域の補強（動画2・動画3）。
5. 3つの役割を分けるために、Chord Low は Channel EQ で 2kHz 以上を少し下げ、Chord High は 300Hz 以下をローカットする（EQ の値は一般知識）。
6. **ピッチを上げ下げする効果**（動画1: コードとベースにピッチのオートメーション、動画3: ピッチベンドとフィルターで「デン」と下がる）:
   - ピアノロールの下の `MIDI Draw`（またはピアノロールのメニュー `View > MIDI Draw > Pitch Bend`）を開く → ピッチベンドの線を描けるようになる。
   - ドロップの区切り（例: 28小節目の最後の1拍）で、ピッチベンドを中央から一番下まで下げる線を描く → 音が「デン」と下がる。
   - 音源側のピッチベンドの幅を ±12（1オクターブ）程度にする（Alchemy・Retro Synth の Pitch Bend の Range 設定。場所はスクリーンショットで探す）。
   - **代替（動画外）**: 音源で幅が変えられない場合は、チャンネルストリップに `Pitch > Pitch Shifter` を挿し、`Semi Tones` をオートメーションで 0 → −12 に動かす。
7. **スクリーンショット**: 3つのリージョンが同じ小節にあり、オクターブがずれていることを確認する。

### 3-7. ベース（Mid Bass ＋ Sub Bass ＋ 808）

1. Sub Bass に 17〜40小節（ビルドアップから）、Mid Bass に 25〜40小節（ドロップから）のリージョンを作る（動画3: ビルドアップまではサブだけ、ドロップでミッドベースが入る）。
2. リズムは**ベタ打ち**（1小節＝1つの長い音、C9 の部分だけ2拍）でよい（動画2）。音は 3-3 の表のベースの列。サブは F1〜C2、ミッドは F2〜C3。
3. 動画3の目安: ベースの最低音は 37Hz くらいまで（それより下は形が崩れる）、一番上が 70Hz くらいだと高すぎる。F1 ≒ 44Hz、A1 ≒ 55Hz、C2 ≒ 65Hz なので、この表の範囲は目安に収まる（周波数の換算は一般知識）。
4. Mid Bass に `Channel EQ` → ローカット（High Pass）を **100Hz** あたり → 100〜300Hz が中心になる（動画2）。
5. Sub Bass に `Channel EQ` → ハイカット（Low Pass）を 100Hz 前後 → **50Hz あたり**が中心になる（動画2）。
6. 動画3: ミッドベースはサブベースと干渉しないように下をばっさり切り、横に広げている。Logic では Mid Bass に `Imaging > Stereo Spread` などを挿して広げる（**代替（動画外）**）。サブは中央のまま。
7. 動画3: ベースにリミッターを挿して音量を揃えている。Logic では `Dynamics > Limiter` を最後に挿す（**代替（動画外）**。動画は FL の Fruity Limiter）。
8. 808（ビルドアップ）: Sampler で 808 系の音を読み込む → `Distortion > Overdrive` または `Distortion` を挿して歪ませる（動画1は「何かのディストーションプラグイン」。プラグイン名は字幕から読み取れない）。
9. **スクリーンショット**: EQ の画面で、Mid Bass のローカットと Sub Bass のハイカットの位置を確認する。

### 3-8. ドラム（Drum Machine Designer ＋ Step Sequencer）

1. Drums トラックで `Y` → Library → `Electronic Drum Kit`（Drum Machine Designer）から1つ選ぶ → パッドにキック・スネア・クラップ・ハイハット・クラッシュが並ぶ。
2. 右クリック → `Create Pattern Region` → Step Sequencer のパターンリージョンができる。パターンの長さは1小節、ステップは16分音符。
3. **ドロップ（ハーフテンポ）**（3本共通、動画2が具体的）: 1小節16ステップのうち
   - キック: ステップ1（1拍目）。動画1は「キックはコードと同じタイミング」なので、コードが鳴る1拍目に必ず入れる。必要ならステップ11（3拍目の裏）にも足す（一般知識）。
   - スネア＋クラップ: ステップ9（3拍目）だけ → ハーフテンポになる。
   - ハイハット: 8分音符（ステップ1・3・5…）を基本に、ところどころ 32分の連打（Step Sequencer の編集モード `Repeat` でそのステップを2連打）を入れる → トラップ風（動画2）。
   - クラッシュ: ドロップの頭（25小節目の1拍目）と、コードが鳴り直す小節の頭（動画3は「コードと一緒にクラッシュ、必ず鳴らす」、動画1は「キックと同じタイミング」）。
4. **ビルドアップ（ジャージークラブ風）**（動画3の「ドンドン・ドドド」。ステップの並びは一般知識）: キックをステップ1・5・9・11・13 → 「ドン・ドン・ドドド」に聞こえる。動画3は「四つ打ち（ステップ1・5・9・13）でもよい」とも言っている。
5. **A メロ2**: ハイハットとパーカッションだけ（キックは控えめ）。動画3はループ素材の切り貼りを勧めている。**代替（動画外）**: `O`（Loops ブラウザ）で「Hi Hat」「Percussion」など、テンポに追従する Apple Loops を探してオーディオトラックに置き、`⌘T`（Split at Playhead）で切って並べ替える。
6. **ビルドアップのスネアロール＋ピッチ上げ**（動画1）: 21〜24小節にスネアを 8分→16分→32分と細かくしていく → Drum Machine Designer のスネアのパッドを選び、Quick Sampler の `Pitch`（Tune）をオートメーションで 0 から +12 まで上げる → スネアがだんだん高くなる。オートメーションが付けにくければ、スネアだけ `Track > Bounce in Place`（`⌃B`）でオーディオにして `Pitch Shifter` をオートメーションする（**代替（動画外）**）。
7. **フィル**（動画1）: ドロップの区切り（32小節目など）にスネア・タムを1拍ぶん入れる。動画3は「ドロップ直前にフィルが見つからなかったので、代わりにコードのカットオフを一度落とした」と話している。
8. **FL の「Cut itself」**（動画3。前のクラッシュを次のクラッシュで止める機能）の **代替（動画外）**: Drum Machine Designer のクラッシュのパッドで Quick Sampler の `Mode` を Mono にする（またはチョークグループを設定）→ 次の音で前の音が切れる。
9. **スクリーンショット**: Step Sequencer の画面で各列のステップの位置を確認する。

### 3-9. サイドチェイン

動画は3本とも Kickstart（Nicky Romero のプラグイン）を使っている。Logic にはないので、**代替（動画外）**として Compressor のサイドチェインを使う。

1. Ghost Kick トラックを作る（Drum Machine Designer のキックだけ、またはキックのサンプルを Quick Sampler に読み込む）→ ドロップ（25〜40小節）の毎拍1回（ステップ1・5・9・13）にキックを入れる。※動画のダッキングは聞こえ方を均すため一定の間隔で効かせる使い方なので、実際のキックの位置と別にしてよい（一般知識）。
2. Ghost Kick のチャンネルストリップの `Output` を `No Output` にする → 音は出ないがサイドチェインの信号には使える（一般知識）。
3. `X`（Mixer）→ Chord Saw・Chord Low・Chord High・Mid Bass・Lead などを選ぶ → `Track > Create Track Stack…`（`⇧⌘D`）→ `Summing Stack` を選ぶ → まとめたトラック（Bus）ができる。
4. そのまとめたトラックの Audio FX に `Dynamics > Compressor` を挿す → プラグイン画面の右上の `Side Chain` メニューで `Ghost Kick` を選ぶ → キックが鳴るたびに音量が下がる。
5. 値の目安（一般知識）: Ratio 8:1 以上、Attack 0〜5ms、Release 100〜200ms（160 BPM の1拍は 375ms）、Threshold はゲインリダクションのメーターが −6〜−10dB 程度振れるまで下げる。
6. Sub Bass にも同じようにかける（サブとキックがぶつからないように）。
7. **スクリーンショット**: Compressor の `Side Chain` 欄に Ghost Kick が表示され、再生中にゲインリダクションのメーターが拍ごとに振れているか確認する。
8. 別の方法（**代替（動画外）**）: Compressor の代わりに、まとめたトラックの `Volume`（または `Gain` プラグインの Gain）をオートメーションで1拍ごとに「下げてすぐ戻す」形に描いてもよい。

### 3-10. FX（ライザー・リバースシンバル・インパクト）

1. FX 用のオーディオトラックを作る（`Track > New Audio Track`、`⌥⌘A`）。
2. `O`（Loops ブラウザ）の検索欄に「Riser」「Uplifter」「Sweep」「Downlifter」「Impact」「Cymbal」などを入れて探す → 見つかったものをトラックにドラッグ（どの名前の素材があるかは Logic のバージョンと追加コンテンツ次第なので、画面で確かめる）。
3. **ライザー**（3本共通）: ビルドアップの 17〜24小節に置き、ドロップの頭で終わるようにする。素材がなければ **代替（動画外）**: ES2 か Retro Synth でノイズ（Noise）だけを鳴らす長い1音を置き、`Filter > AutoFilter` のカットオフを 8小節かけて上げるオートメーションを描く → だんだん明るくなるノイズのライザーになる。
4. **リバースシンバル**（動画1・動画2）: クラッシュの音をオーディオにする（Drums のクラッシュだけのリージョンを作り `⌃B` の Bounce in Place、またはクラッシュの Apple Loop）→ そのオーディオリージョンを選び、Region inspector の `Reverse` にチェック（なければ、リージョンをダブルクリックして Audio File エディタの `Functions > Reverse`。これは元のファイルを書き換えるので、事前にユーザーに確認する）→ 逆再生のシンバルになる。区切りの小節（9・17・25小節目）の**直前で終わる**ように置く。
5. **インパクト・ダウンリフター**（動画2）: ドロップの頭（25小節目）と A メロの頭に置く。
6. **ドロップ直前の「キュイン」**（動画3）・**ボイス**（動画2）: Apple Loops に近いものがあれば使う。
7. **ボーカルチョップ**（動画1）: **代替（動画外）**: ボーカル系の Apple Loop を Quick Sampler に読み込み、`Slice` モードにする → 鍵盤ごとに切れ端が割り当てられる → ビルドアップに短く打ち込む。動画1の Endless Smile（エフェクトを一気に深くするプラグイン）の代わりに、`AutoFilter` と `ChromaVerb` の Mix をオートメーションで上げていく。
8. **高音のノイズ FX**（動画3）: Retro Synth か ES2 のノイズまたは歪ませた音を、曲の**キーの5度**（C メジャーなら G、C# メジャーなら G#）の高い音で鳴らし続ける → 上の帯域の隙間が埋まる。
9. **ビルドアップの終わりのローカット**（動画3が勧めている）: ビルドアップの最後の1〜2小節で、まとめたトラック（またはマスター以外の主要トラック）に `Channel EQ` の High Pass を挿し、周波数を少しだけ上げるオートメーションを描く。動画3は「EDM のように極端にはしない」「直前でちょっとだけ」と言っている。
10. **スクリーンショット**: FX トラックの各リージョンが区切りの小節線の前後にあるか確認する。

### 3-11. ミックス

1. `X` でミキサーを開き、全トラックのフェーダーを一度 −6dB 前後に揃えてから、ドラム（キック）→ベース→コード→メロディの順で音量を決める（一般知識）。
2. ベースとサブ以外のトラックは `Channel EQ` で低域をローカットする（動画3。どこまで切るかは「曲による」と話している）。目安として 100〜150Hz（一般知識）。
3. **Haas 効果で脇役を左右に**（動画3）: **代替（動画外）**: パッド・アルペジオ・プラックのおかずなど脇役のトラックに `Delay > Sample Delay` を挿し、片側（L か R）だけを 10〜20ms 遅らせる（値は一般知識）→ 左右に広がる。**メインのコードとメロディにはかけない**（動画3: 音像がぶれるので主役は真ん中）。
4. 横に広げる（動画3のステレオイメージャー）の **代替（動画外）**: `Imaging > Stereo Spread` または `Direction Mixer` の Spread。
5. リバーブは薄く（動画3はコードのリバーブが 4%）。**代替（動画外）**: 動画3の EOS・Dubstation の代わりに、`Reverb > ChromaVerb` と `Delay > Tape Delay` を Send（Bus）で使う。
6. 動画3: リードのビットクラッシャーで出る耳障りな高域はハイカットしている。リードがうるさいときは `Channel EQ` で高域を少し下げる。
7. **最後の移調**: 全 MIDI リージョンを選び（オーディオの FX は除く）、Region inspector（`I`）の `Transpose` を `+1` にする → 全体が C# メジャーになる（動画3のキー）。LCD のキー表示も `C#maj` にする。Drum Machine Designer のドラムは移調しない（音程が変わるため除外して選ぶ）。
8. **スクリーンショット**: ミキサー全体で、どのトラックのピークも赤くなっていないか確認する。

### 3-12. マスター（書き出しの前）

動画3のマスタリングは FL Studio と外部プラグイン（OTT、Ozone、FabFilter Pro-Q・Pro-L、Invisible Limiter など）。以下は **代替（動画外）**。

1. Stereo Out（マスター）に次の順で挿す:
   1. `Dynamics > Multipressor`（OTT の代わり。動画3は OTT を「Depth 低め」で高域を出すために使っている → 効きは浅く）
   2. `Dynamics > Compressor`（全体のまとまり。軽く）
   3. `EQ > Channel EQ`（動画3: こもる帯域を少し削る）
   4. `Dynamics > Adaptive Limiter`（Ozone の Maximizer・Invisible Limiter の代わり。Out Ceiling は −1.0dB 程度。一般知識）
   5. `Metering > Loudness Meter`（音量の確認用）
2. Logic Pro 10.8 以降なら **Mastering Assistant** でも代用できる（動画3は Ozone の AI に一度処理させてから不要な部分を外している。一般知識）。
3. 動画3の注意: **ビルドアップがドロップより大きくなると、ドロップを上げたときにビルドアップが音割れする**。ビルドアップの終わりのローカット（3-10の9）と音量を確認する。
4. 動画3の音量の目安: ストリーミング用はできるだけ大きくしたいが、潰しすぎると音が破綻する、と話している。具体的な LUFS の目標は動画では決めていないので、ユーザーに確認する。
5. 書き出し: ユーザーに確認してから `File > Bounce > Project or Section…`（`⌘B`）→ 形式（WAV など）・ビット深度・範囲を確認 → 書き出し。動画3は、マスタリングを別のプロジェクトで行うときは **32bit float** で書き出している（0dB を超えても割れずに残る）。
6. **スクリーンショット**: Bounce の設定画面を書き出し前に撮り、ユーザーに見せて確認をもらう。
