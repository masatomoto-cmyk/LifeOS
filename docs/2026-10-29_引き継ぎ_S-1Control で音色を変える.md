# 引き継ぎ：S-1 Control で S-1 の音色を実際に変える（2026-10-29）

## やってほしいこと
Logic Pro に入れた「Roland S-1 Control」プラグインのつまみを Claude が画面操作で動かし、**S-1 の音色を実際に変えて**ほしい。
変えたら、録音で音が変わったことを数字で確かめて報告すること。

目標の音色（例）：太いベース
- OSC：SAW 127、SUB 80 くらい、RANGE は 16'（低め）
- FILTER：FREQ 40 くらい、RESO 30 くらい、ENV 60 くらい
- ENV：ATTACK 0、DECAY 50、SUSTAIN 40、RELEASE 20
（音色はユーザーに聞いて変えてよい）

## 今の環境
- S-1 は USB で Mac に接続。MIDI の送り先は `S-1 MIDI IN`。**受信チャンネルは 12**
- Logic のプロジェクト「claude project」のトラック 14「S-1」
  - 音源は External Instrument（MIDI Destination：S-1、チャンネル 12）
  - MIDI FX に「Roland S-1 Control」が挿さっている。**今はバイパス（一時停止）中**
- 自作コマンド `~/.local/bin/s1`（本体 `~/Documents/LifeOS/bin/s1ctl.py`、Python は `~/.venvs/s1`）
  - `s1 list` / `s1 set cutoff=40` / `s1 play --dur 2 "C3"` / `s1 test` / `s1 panic`
  - `s1 panic` は全128音のノートオフも送る（S-1 は「全音停止」の CC123/120 を無視するため）
- MIDI の横取り記録：`~/.venvs/s1/bin/python ~/Documents/LifeOS/bin/midispy.py 記録.log`（仮の出口「S-1 Spy」を作る）

## いちばん大事な注意（今日分かったこと）
**S-1 Control は、動いている間ずっと「ピッチベンド 0」を毎秒約1500件、S-1 に送り続ける。** 全メッセージが重複して届く。画面を閉じても止まらず、バイパスすると止まる。
今日はこれが原因と思われる不具合が起きた（未確認だが辻褄は合う）。
- 音が鳴りっぱなしになった（ノートオフが抜けた）
- S-1 が本体の鍵盤でも鳴らなくなった。直ったのは電源の入れ直し

なので、次のどちらかで進めること。
1. **おすすめ：ピッチベンドを捨てる仕掛けを足す。** S-1 Control の後ろの MIDI FX に Logic 純正の「Scripter」を入れ、ピッチベンドだけ捨てるスクリプトにする。たとえば `function HandleMIDI(e){ if (e instanceof PitchBend) return; e.send(); }`。そのあと `midispy.py` で、ピッチベンドが届かないことを確かめてから S-1 に戻す（**未検証の案**）
2. **短時間だけ使う：** バイパスを外す → つまみを動かす → すぐバイパスに戻す。終わったら `s1 test` で S-1 が鳴るか確かめる

## 画面操作について
- プラグインの画面は別のプロセス（AUHostingService）が描いている。そのため、つまみを背景操作（app_*）で動かすことはできない
  - できること：画面のスクリーンショット、閉じるボタン、バイパスの電源ボタン
- つまみのドラッグには**全画面操作の許可**（request_full_control）が要る。今日は2回、許可の確認が時間切れになった。**頼む前に「画面に許可の確認が出るので見ていて」とユーザーに伝える**
- 選択メニュー（MIDI Destination など）も背景操作では開けない。全画面操作か、ユーザーに頼む
- FREQ つまみは縦ドラッグで動く。今日は約290px のドラッグで 99→0 になった

## 音が変わったかの確かめ方
録音デバイスは ffmpeg（avfoundation）の `:1` = S-1。音を鳴らしながら3秒ほど録音し、全体の音量と 2kHz 以上の音量を比べる（`astats` と `highpass=f=2000`）。
今日の実測（プラグインで FREQ を変えたとき）：FREQ 0 → -65dB、FREQ 127 → -46dB。

## もし S-1 がおかしくなったら
1. プラグインをバイパスする
2. `s1 panic` を送る
3. 本体の鍵盤でも鳴らないときは、**S-1 の電源を入れ直してもらう**（今日はこれで2回とも直った）
- 電源を入れ直すと、Logic が「オーディオ装置が使えない」「MIDI ポートの数が変わった」という知らせを出す。OK や「続ける」で閉じてよい

## その他
- `ampmode=127` は送らない
- 段階つまみ（range・lfowave など）は小さな数で送る。range は 3 が標準
- 鳴らしたら最後に `s1 panic`
- Logic の P-6 用トラック（P-6 11・15・12）も送り先が S-1 になっている。S-1 はチャンネル 12 しか受け取らず、P-6 12 は空なので、今は影響なし。S-1 を OMNI（全チャンネル受信）にはしない
- S-1 Control には S-1 本体に音色を保存する機能はない。保存は本体の WRITE ボタンで、ユーザーが行う
